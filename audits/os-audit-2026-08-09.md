## Findings by check

**Routing** — 75 path claims in CLAUDE.md, 74 resolve. The one failure is
`Topbar` (fixed). The other 15 flagged strings are prose, not paths: ellipses
(`app/...`), section-relative names inside the brain table (`tools/index.ts`),
CSS class names (`.metric-up/.metric-down`), a stream name
(`process.stdout/stderr`), and a git ref (`origin/main`). *[poisoning]*

**Index truth** — every `docs/` reference resolves. Both skills
(`graphify`, `os-audit`) carry a real `SKILL.md`, so neither fails silently.

**Freshness** — this project has no external data feeds to freeze: state lives
in D1 and in git, both continuously current. `docs/AUDIT-2026-06.md` and
`docs/PHASES-INTELLIGENCE.md` are 18 days old but describe shipped phases, not
live numbers — history, not staleness.

**Bloat** — CLAUDE.md is **4,647 words**, paid on every session, and grew in
each of the last three PRs. Not yet wrong, but the graph-orchestration section
alone is now ~40 lines. Candidate: move the deep VOAC internals into
`lib/voac/README.md` and leave a two-line pointer. *[bloat]*

**Root hygiene** — 24 root files, all framework-mandated config, the manual, the
README, or gitignored local artifacts (`dev.db`, `e2e.db`, `*.tsbuildinfo`).
`dev.db` must stay at root — the dev server reads it there. Clean.

**Context placement** — the always-loaded layer states conventions and
doctrine, not live values. The one counter that appears (the daily LLM cap) is
named as an env var rather than a copied number, which is the correct form.
